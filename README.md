# Suzhou Campus Hub（苏州校区学生助手）

一个由学生自发建设的非官方校园服务网站 MVP，定位为“东南大学苏州校区首届本科生的信息、学习与校园互助平台”。第一阶段首页聚焦新生指南、校园地图、信息广场、全英课堂助手、学习资源和校园互助。

> 本平台由学生自发建设，与学校官方无隶属或授权关系。平台信息仅供参考，请以学校官方通知为准。

项目不使用学校校徽或官方视觉规范，不采集学生证照片、身份证号码和精确位置。演示内容均标有“演示信息”。

## 已实现功能

- 邮箱、昵称、专业、入学年份与邀请码注册；注册后待管理员人工认证
- 安全密码哈希、登录/退出、修改密码与忘记密码占位页
- 信息广场：分类、搜索、分页、最新/热门排序、详情、评论、收藏、举报、前台匿名
- 已认证学生发帖；新帖子默认待审核
- 新生指南、FAQ 和可替换的静态校园示意图
- 全英课堂助手：专业/分类筛选、搜索、学生经验投稿与审核
- 家教模块以功能开关保留：默认隐藏公开教师列表和家长需求表单，保留低调申请入口与管理员管理能力
- 用户中心：认证状态、帖子、收藏、调查记录、修改密码和开发中申请入口
- 管理后台：用户、帖子、评论、举报、教师、家教需求、攻略、英语资料和地图地点管理
- 调查中心：公开/登录调查、8 种题型、匿名 token 防重复、来源参数、进度与移动端填写
- 调查管理：建卷、复制、问题排序、发布/暂停/关闭、有效性审计、筛选统计、人工文本标签、决策摘要、匿名汇总、CSV/XLSX 和二维码
- 用户协议、隐私说明、社区规范以及 403/404/413/500 页面
- CSRF、服务端校验、HTML/脚本输入拒绝、角色权限、5MB 图片上限和随机文件名

## 技术与结构

- Python 3.12、Flask、Jinja2
- Flask-SQLAlchemy、Flask-Migrate、Flask-Login、Flask-WTF
- 开发环境使用 SQLite；`DATABASE_URL` 可切换 PostgreSQL
- 生产环境强制 PostgreSQL、HTTPS 基础地址和至少 32 字符密钥
- 可信反向代理支持、Secure Cookie、安全响应头和数据库健康检查
- 自写移动端优先响应式 CSS
- pytest 自动化测试
- Application Factory + 模块化业务蓝图

```text
app/
  models/             数据模型
  routes/             auth、main、posts、guides、english_hub、tutoring、admin
  forms/              WTForms 与服务端校验
  utils/              权限、安全输入与图片上传
  templates/          中文 Jinja 页面
  static/             样式与上传目录
tests/                MVP 验收测试
migrations/           Alembic 数据库迁移
instance/             本地 SQLite 数据库（不提交）
```

## Windows 本地运行

以下命令在 PowerShell 中执行。需要先安装 Python 3.12 或更高版本。

### 1. 创建并激活虚拟环境

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

若 PowerShell 阻止当前会话运行激活脚本，可先执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

### 3. 配置环境变量

```powershell
Copy-Item .env.example .env
```

打开 `.env`，把 `SECRET_KEY` 替换为随机长字符串。开发环境可保留默认 SQLite 地址。`APP_BASE_URL` 用于生成调查二维码中的完整链接；`FEATURE_SURVEYS_PUBLIC=False` 可暂停所有普通用户填写；`FEATURE_TUTORING_PUBLIC=False` 会隐藏家教导航、教师列表和家长表单，但管理员仍可管理历史数据。可用下面的命令生成密钥：

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

### 4. 初始化与迁移数据库

仓库已经包含初始迁移文件。新环境只需运行：

```powershell
$env:FLASK_APP = "run.py"
flask db upgrade
```

仅在全新开发分支创建迁移时使用：

```powershell
flask db migrate -m "describe schema change"
flask db upgrade
```

### 5. 导入演示数据

```powershell
flask seed --reset
```

`--reset` 会清空当前数据库并创建完整演示数据，只应在本地开发数据库使用。以后希望保留已有数据时，运行 `flask seed` 即可；已有数据时命令会安全退出。

### 6. 启动网站

```powershell
flask run
```

浏览器访问 `http://127.0.0.1:5000`。

### 7. 运行测试

```powershell
pytest -q
```

测试使用内存数据库，且仅在测试配置中关闭 CSRF，不会修改本地演示数据库。

## 家教模块隐藏开发状态

默认配置：

```dotenv
FEATURE_TUTORING_PUBLIC=False
```

- 首页和主导航不显示家教入口
- 游客和普通学生访问 `/tutoring` 或 `/tutoring/request` 会得到 404
- 已认证学生可在用户中心“更多申请”中找到低调的教师申请入口
- 管理员仍可直接访问教师列表、家长需求表单和后台需求管理
- 未来确认上线时，将环境变量改为 `True` 并重启网站即可恢复公开前台

## 调查中心使用方式

- 演示调查公开地址：`http://127.0.0.1:5000/s/freshman-needs`
- 来源统计示例：`http://127.0.0.1:5000/s/freshman-needs?source=wechat_group`
- 管理员登录后进入“管理后台 → 调查管理”
- 管理员可以创建草稿、编辑基本信息、添加/排序问题、复制、发布、暂停或关闭调查
- “分享与二维码”页面提供完整公开链接和 PNG 二维码下载
- “统计”页面显示浏览量、提交量、有效答卷、完成率、平均填写时间和每日趋势，并可按日期、专业、登录状态和来源筛选
- 选择题显示人数或选择次数、比例和排名；评分题显示平均分、中位数、分值分布和高分区间比例
- 文本题由管理员逐条人工添加多个标签，可按标签筛选并统计标签次数；平台不会用自动结论替代人工核对
- 管理员可将答卷标记为有效、无效或测试；普通统计默认只计算有效答卷，状态变更和删除会写入不含回答内容的审计记录
- “产品决策摘要”按有效答卷比例提供高/中/观察参考标记，管理员可以手动调整或恢复自动判断
- 匿名 HTML 汇总不含单条文本、账号信息或联系方式；联系方式类题目只出现在管理员原始答卷和单独的“内测邀请名单”导出中
- CSV 使用 UTF-8 BOM，Excel 可直接打开中文；XLSX 为原生工作簿，二者继续保留管理员原始数据导出能力
- 普通登录学生可在用户中心查看自己的参与记录，但看不到其他人的回答

匿名调查只保存浏览器随机 token，不保存完整 IP，也不进行设备指纹追踪。同一匿名 token 或同一登录账号默认只能提交一次；管理员可在调查基本信息中显式开启重复提交或答卷修改。

## 专业字段规范

用户专业由统一代码保存，界面固定显示为“机器人工程”“智能制造工程”“新能源科学与工程”或“其他”，不再依赖自由文本。历史上无法判断具体归属的合并记录会迁移为 `pending_confirmation`：用户下次登录后需要在个人中心从机器人工程、智能制造工程中重新确认；确认前管理员后台显示“待确认”，调查统计也不会把该用户计入任何具体专业。

学习资源使用相同的专业代码，并额外允许“通用”分类。当前无真实用户数据的首次测试部署可直接执行迁移；以后已有真实数据时，应先使用 `pg_dump` 导出到数据库之外并验证恢复。迁移只标记不确定记录，不会自动猜测真实专业，也不会在同一数据库中创建所谓“备份表”。

## 部署建议

项目已经包含 `wsgi.py`、Gunicorn 配置、`Dockerfile`、`.dockerignore`、GitHub Actions 和生产环境变量模板。当前根目录的 `render.yaml` 是零付费短期测试配置（Free Web + Free PostgreSQL、无持久化磁盘）；`render.production.yaml` 保留未来正式付费部署能力，不会被默认 Blueprint 自动创建。两种配置都会执行数据库迁移，并通过环境变量幂等创建首个管理员。完整步骤见 `docs/DEPLOYMENT.md`，备份与恢复见 `docs/BACKUP_AND_RESTORE.md`。

关键约束：

- 本地继续使用 SQLite 和 Flask 开发服务器
- 生产必须使用 Gunicorn、PostgreSQL、HTTPS 和强 `SECRET_KEY`
- 公网仅开放首页、认证、法律页面、健康检查和允许匿名的调查
- 信息广场、指南、地图、全英课堂和学习资源要求登录且学生认证通过
- 单实例生产可使用 Blueprint 配置的持久化上传磁盘；多实例前必须迁移到对象存储
- 部署发布阶段执行 `flask db upgrade`，不要在生产环境执行 `seed --reset`
- 上线前配置定时 PostgreSQL 备份，并至少完成一次隔离恢复演练

## 当前已知限制

- 忘记密码仅为安全占位页，尚未接入邮件重置流程
- 校园地图为示意图，不提供精确定位
- 家教模块默认处于隐藏开发状态；公开前台只有在显式开启功能开关后才可访问
- 图片可保存在单实例持久化磁盘；当前实现仍不适合多实例生产部署
- 内容审核为人工流程，尚无通知中心与申诉工作流
- 管理后台 CRUD 以 MVP 快速维护为目标，未加入批量操作和富文本编辑
- 调查暂不支持复杂条件跳题；演示调查的内测联系方式题始终显示，并明确标注选填和用途
- 调查结果处理为描述统计和人工标注，不包含交叉分析、显著性检验或自动生成结论
